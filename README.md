# PAWHAVEN – Assignment 3 / Midterm Version

PAWHAVEN is a responsive pet shop and pet adoption website created by the SE-2504 team.

## Team members and pages
- Miras Kamaladin — Home and Shop
- Ayaulym Amankeldykyzy — Our Pets and Adoption
- Dias Aibekuly — About Us and Contact

## Technologies
- HTML5
- CSS3
- Bootstrap 5.3.3
- Flexbox / CSS Grid where custom styling is needed
- Bootstrap responsive grid and responsive navbar
- Bootstrap Carousel on the Our Pets page

## Responsive design
The project uses Bootstrap breakpoints and grid classes such as `col-12`, `col-md-6`, `col-lg-4`, `col-lg-3`, and `col-xl-2`. Images use Bootstrap responsive image classes so they do not overflow on small screens.

The main navigation uses Bootstrap's responsive navbar and collapse component. The page layout also has a Bootstrap-first responsive structure, so the site's basic layout remains responsive even if the custom `style.css` file is removed.
